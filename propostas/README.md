# Propostas de conhecimento

Arquivos `AAAA-MM-DD-<tema>.md` gerados pela skill `propor-conhecimento` nos repositórios das empresas. Chegam por
pull request; o CI passa o verificador de texto (dado de empresa, segredo, frase de ordem ao agente) e o mantenedor
revisa antes de levar o conteúdo para `conhecimento-geral/`. Depois de incorporada, a proposta pode ser apagada.
